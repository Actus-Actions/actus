# Actus 快速上手

> 从零开始，5 分钟跑通第一个动作。

## 1. 环境准备

- Python 3.10+
- vools 基座 + vools.actus 引擎：`pip install "vools[actus]>=0.7.9"`
  （0.7.8 起这个 extra 才装得出来；`vools.actus` 是独立发行包，只装 `vools` 没有它。
  下限 0.7.9：`sigma` / `scattered` / `repo` / `publisher` 与 `runner.is_routable`
  都不在 0.7.8 里。本机开发走兄弟源码树 `E:\IDEProjects\AI\vools` 时由
  `engine/_vools_bootstrap.py` 挂载）
- 可选：WSL（用于 Linux 侧动作）

```bash
# 验证环境 —— 两条都要过：只 import vools 测不出引擎在不在
python --version
python -c "import vools; print(vools.__version__)"
python -c "import vools.actus; print(vools.actus.__file__)"
```

## 2. 安装 Actus

```bash
cd E:\IDEProjects\AI\Actus\engine
python -m actus scan          # 扫描动作，生成索引
python -m actus list          # 查看已注册动作
```

## 3. 执行第一个动作

```bash
# 最简单的 hello 动作
python -m actus run actus.hello --confirm

# 带参数执行
python -m actus run actus.textstats '{"text": "你好 Actus"}'

# 诊断环境问题
python -m actus doctor

# 校验所有动作
python -m actus validate
```

## 4. 编写自己的动作

在 `actions/` 目录下新建 `.actus.md` 文件：

```markdown
---
name: My Action
description: 我的第一个动作
version: 1.0.0
author: You
tags: [demo]
trust: trusted
---

# My Action

```json #!cfg
{
  "id": "actus.my.action",
  "name": "my_action",
  "version": "1.0.0",
  "trust": "trusted",
  "deps": [],
  "entry": "main",
  "description": "我的第一个动作",
  "author": "You",
  "args": {
    "type": "object",
    "properties": {
      "name": { "type": "string", "description": "名称" }
    },
    "required": ["name"]
  }
}
```

```python #!run tag=main
"""
my.action — 我的第一个动作。
"""

def main(name="World"):
    return {"status": "ok", "message": f"Hello, {name}!"}
```

```

## 5. 注册并验证

```bash
cd E:\IDEProjects\AI\Actus
python -m actus scan          # 重新扫描
python -m actus run actus.my.action '{"name": "Actus"}'
python -m actus validate      # 校验
```

## 6. 接入 AI（MCP）

```bash
# 启动聚合 MCP server
python -m actus mcp
```

AI 客户端（Claude Desktop / Cursor 等）连接后，可用自然语言驱动动作执行。

## 7. 快捷面板

```bash
python -m panel

```

## 常用命令速查

### 基础查询

| 命令 | 说明 |
|---|---|
| `actus scan` | 扫描动作，重建索引 |
| `actus list` | 列出所有动作 |
| `actus info <id>` | 查看动作详情 |
| `actus search <query>` | 搜索动作 |

### 执行与编排

| 命令 | 说明 |
|---|---|
| `actus run <id>` | 执行动作（`--confirm` 放行 audit 级） |
| `actus preview <id>` | 干跑（仅解析不执行） |
| `actus workflow <name>` | 运行 DAG 工作流 |
| `actus exec <lang>` | 执行多语言代码片段 |

### 安装与发布

| 命令 | 说明 |
|---|---|
| `actus install <url>` | 从 Git 仓库安装动作 |
| `actus uninstall <name>` | 卸载已安装仓库 |
| `actus publish <id>` | 发布动作到 GitHub 仓库 |
| `actus search --remote` | 搜索远程公开动作 |

### 治理与信任

| 命令 | 说明 |
|---|---|
| `actus validate` | 校验动作（Schema + 依赖图） |
| `actus trust <id>` | 查看/修改信任级别 |
| `actus approve <id>` | 审批动作（audit → trusted） |
| `actus deps <id>` | 检查动作依赖 |

### 统计与排行榜

| 命令 | 说明 |
|---|---|
| `actus stats` | 统计概览 |
| `actus stats <id>` | 单个动作统计（使用量/成功率/耗时） |
| `actus stats --me` | 当前用户的使用统计 |
| `actus leaderboard` | 动作排行榜 Top 20 |
| `actus leaderboard --category system` | 分类排行榜 |
| `actus leaderboard --trending` | 趋势榜（最近 7 天） |
| `actus leaderboard --recent` | 新动作榜（最近 30 天） |

### 用户与协作

| 命令 | 说明 |
|---|---|
| `actus user register --github <用户>` | 注册用户（生成匿名 ID） |
| `actus user status` | 查看用户配置 |
| `actus pr-review <pr_url>` | 审核 PR + 合并公开动作 |

### 集成

| 命令 | 说明 |
|---|---|
| `actus mcp` | 启动 MCP server |
| `actus dialog` | 弹出交互弹窗 |
| `actus triggers` | 热键触发器管理 |
| `actus health` | 系统健康检查 |
| `python -m panel` | 快捷面板（Ctrl+Alt+Space） |

## 统计上报说明

Actus 本地统计默认开启，存储在 `~/.actus/stats/` 目录：

- **隐私保护**：使用匿名 ID（SHA256），不可逆追踪
- **本地优先**：先存本地 JSONL，定时同步到私有仓库
- **可选关闭**：`ACTUS_STATS=0` 关闭统计上报

```bash
# 查看统计文件
ls ~/.actus/stats/
# 2026-09-20.jsonl  ← 每日使用记录（JSONL）
# installs.json     ← 安装统计
```
